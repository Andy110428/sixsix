# 텔레그램 설정 가이드 (쉬운 버전)

> ⚠️ 이 가이드의 **B(스터디방 봇)**는 업데이트를 사이트에 적용한 **다음에** 따라 하세요.
> **A(PC 원격작업)**는 사이트와 상관없어서 언제든 해도 됩니다.

## 먼저 알아둘 것: 봇은 2개 씁니다

- **기존 봇**(지금 신청 알림이 오는 봇) → **스터디방 관리용**
- **새 봇**(A에서 새로 만듦) → **내 PC 원격작업용**

봇 하나를 두 군데서 같이 쓰면 서로 메시지를 뺏어가서 고장 납니다. 그래서 꼭 나눠서 씁니다.

---

## A. 텔레그램으로 내 PC에 일 시키기 (Windows)

### 제일 헷갈리는 것: 입력하는 곳이 2군데예요

| | 🟦 **PowerShell** | 🟧 **Claude Code** |
|---|---|---|
| 여는 법 | 시작 버튼 → `PowerShell` 검색 → 실행 | PowerShell 창에 `claude` 입력 → 엔터 |
| 생김새 | 줄 맨 앞에 `PS C:\Users\...>` 가 보임 | Claude 로고가 뜨고 아래에 `>` 입력칸이 생김 |
| 입력하는 것 | 프로그램 설치, `claude ...` 실행 명령 | `/` 로 시작하는 명령 (예: `/plugin ...`) |
| 빠져나오기 | 창 닫기 | `/exit` 입력 → 다시 🟦 PowerShell로 돌아감 |

> 같은 검은 창이지만, `claude`를 입력하면 그 창이 🟧 Claude Code로 바뀌고, `/exit`를 입력하면 다시 🟦 PowerShell로 돌아와요.
> **규칙: `/` 로 시작하는 건 전부 🟧 Claude Code, 나머지는 전부 🟦 PowerShell.**

---

### 1단계 – 프로그램 설치 (처음 한 번만)

**① Claude Code 설치** — 🟦 PowerShell에 입력
```
irm https://claude.ai/install.ps1 | iex
```
- 끝나면 PowerShell 창을 **닫고 새로 엽니다.**
- 🟦 PowerShell에 `claude` 입력 → 엔터 → 화면 안내대로 로그인(지금 쓰는 Claude 계정)
- 로그인이 끝나면 `/exit` 입력해서 🟦 PowerShell로 돌아옵니다.
- "Git이 필요하다"는 말이 나오면 https://git-scm.com/download/win 에서 설치하고 다시 해보세요.

**② Bun 설치** — 🟦 PowerShell에 입력
```
powershell -c "irm bun.sh/install.ps1 | iex"
```
- 끝나면 PowerShell 창을 **닫고 새로 엽니다.**

**③ 크롬 확장 설치** — 크롬 브라우저에서
- 크롬 웹스토어에서 "Claude in Chrome" 검색 → 설치 → 같은 Claude 계정으로 로그인

### 2단계 – 새 봇 만들기 — 텔레그램 앱에서

1. **@BotFather** 검색 → 대화 시작
2. `/newbot` 보내기
3. 봇 이름 입력 (아무거나, 예: `내PC비서`)
4. 봇 아이디 입력 (영어, 끝이 `bot`, 예: `sixx_pc_bot`)
5. BotFather가 주는 **토큰**(`1234567:ABC...` 모양)을 메모장에 복사해두기

### 3단계 – 연결하기 (처음 한 번만)

**① 작업 폴더 만들기** — 윈도우 탐색기에서
- 바탕화면에 `claude-work` 폴더를 만들고 들어갑니다.
- 폴더 위쪽 **주소창**을 클릭 → `powershell` 입력 → 엔터 → 이 폴더에서 🟦 PowerShell이 열려요.

**② Claude Code 켜기** — 🟦 PowerShell에 입력
```
claude
```
→ 이제 화면이 🟧 Claude Code로 바뀝니다.

**③ 텔레그램 플러그인 설치** — 🟧 Claude Code에 입력
```
/plugin install telegram@claude-plugins-official
```
- 설치 범위를 물으면 **user** 선택
- "Marketplace not found"가 나오면 아래를 먼저 🟧 Claude Code에 입력하고, 위 줄을 다시 입력
  ```
  /plugin marketplace add anthropics/claude-plugins-official
  ```

**④ 새 봇 토큰 넣기** — 🟧 Claude Code에 입력 (뒤에 2단계 토큰 붙여넣기)
```
/telegram:configure 여기에토큰붙여넣기
```

**⑤ 크롬 연결 켜두기** — 🟧 Claude Code에 입력
```
/chrome
```
→ 나오는 메뉴에서 **Enabled by default** 선택

**⑥ 껐다가 텔레그램 모드로 다시 켜기**
- 🟧 Claude Code에 입력 → 🟦 PowerShell로 돌아감
  ```
  /exit
  ```
- 🟦 PowerShell에 입력 → 다시 🟧 Claude Code가 켜짐(이번엔 텔레그램 연결된 상태)
  ```
  claude --chrome --channels plugin:telegram@claude-plugins-official
  ```

**⑦ 내 텔레그램 계정 연결**
- 텔레그램 앱에서 **새 봇**에게 아무 말이나 보내면 → 봇이 **코드**를 답장해요.
- 🟧 Claude Code에 입력 (받은코드 자리에 코드)
  ```
  /telegram:access pair 받은코드
  ```
- 🟧 Claude Code에 입력 (나 말고 다른 사람 메시지는 무시하게 하는 설정 — 꼭!)
  ```
  /telegram:access policy allowlist
  ```

✅ 끝! 이제 텔레그램에서 새 봇에게 "크롬에서 오늘 비트코인 뉴스 찾아서 요약해줘"처럼 보내면 돼요.

### 다음부터 켜는 법 (더블클릭 한 번)

매번 위 ⑥번 명령을 치기 귀찮으면 실행 파일을 만들어두세요. — 메모장에서
1. 메모장에 아래 3줄을 붙여넣습니다. `내이름`은 내 윈도우 사용자 이름으로 바꾸세요.
   ```
   @echo off
   cd /d C:\Users\내이름\Desktop\claude-work
   claude --chrome --channels plugin:telegram@claude-plugins-official
   ```
2. 다른 이름으로 저장 → 파일 형식 **모든 파일** → 파일 이름 `claude-telegram.bat` → 바탕화면에 저장
3. 앞으로는 이 파일을 더블클릭하면 텔레그램 연결된 🟧 Claude Code가 바로 켜져요.

### 꼭 알아둘 것

- **PC가 켜져 있고 이 창이 열려 있을 때만** 동작해요. 윈도우 설정 → 시스템 → 전원에서 **절전 모드를 "안 함"**으로 바꿔두세요.
- Claude가 "이거 해도 될까요?"라고 물으면 대답할 때까지 멈춰요. 자주 멈추면 🟧 Claude Code 창에서 키보드 `Shift + Tab`을 눌러 **auto 모드**로 바꾸세요.
- 사이트 로그인이나 "로봇이 아닙니다" 확인이 나오면 Claude가 멈추고 직접 해달라고 해요.

## B. 스터디방 관리 봇 (기존 봇) — 업데이트 적용 후

### 이렇게 동작해요

1. 새 신청자가 사이트에서 UID 확인 → 시드 예치 O → **"텔레그램으로 신청하기"** 버튼을 누릅니다.
2. 봇 대화창이 열리고, 신청자가 **시작**만 누르면 신청 완료. 이때 봇이 신청자의 **텔레그램 고유번호**를 자동으로 알아내서 UID와 묶어둡니다.
3. 나에게 **[✅ 승인] [❌ 거절]** 버튼이 달린 알림이 옵니다. 시드 예치를 확인하고 승인을 누르면, 봇이 그 사람에게만 쓸 수 있는 초대 링크를 보내줍니다.
4. 입장 후 **30일 동안 거래가 없으면** 정리 대상이 됩니다. 23일째에 경고 DM이 먼저 갑니다.
5. **기존 멤버는 건드리지 않습니다.** 이 방식으로 새로 들어온 멤버만 관리합니다.

### 설정하기 (처음 한 번만, 10분)

**1단계 – 봇을 스터디방 관리자로**
- 스터디방 → 상단 방 이름 누르기 → 편집(연필) → 관리자 → 관리자 추가 → 기존 봇 선택
- 권한 중 **"사용자 차단"**과 **"초대 링크로 사용자 초대"** 두 개를 켜고 저장

**2단계 – Cloudflare에 비밀번호 하나 넣기**
- 비밀번호를 하나 정합니다. **영어와 숫자만** 써서 20자 이상으로 만드세요(예: `sixxBot2026xk39fj28dm`). 메모장에 적어두세요.
- https://dash.cloudflare.com 접속 → **Workers & Pages** → **sixsix** → **Settings** → **Variables and Secrets** → **+ Add**
  - Type: **Secret**
  - Variable name: `TELEGRAM_WEBHOOK_SECRET`
  - Value: 방금 정한 비밀번호
  - **Deploy**(또는 Save) 누르기
- ⚠️ 저장하는 순간 사이트 신청 버튼이 봇 방식으로 바뀝니다. **바로 3단계를 이어서** 하세요.

**3단계 – 주소 하나 열기 (자동 연결)**
- 브라우저 주소창에 아래처럼 입력합니다. `사이트주소`는 평소 들어가는 TEAM SIXX 사이트 주소, `비밀번호`는 2단계에서 정한 값입니다.
  ```
  https://사이트주소/api/telegram-setup?key=비밀번호
  ```
- 화면에 ✅가 뜨고 텔레그램으로 **"연결 테스트 메시지"**가 오면 성공입니다.
- ❌가 뜨면 옆에 적힌 안내대로 고치고 같은 주소를 다시 열면 됩니다.

**4단계 – 스터디방 번호 등록**
- 스터디방 안에서 `/groupid` 를 보냅니다(나만 할 수 있어요). 봇이 `-100`으로 시작하는 번호를 알려줍니다.
- Cloudflare에서 2단계와 똑같이 하나 더 추가합니다.
  - Variable name: `TELEGRAM_GROUP_CHAT_ID`
  - Value: 받은 번호(`-` 포함)
- 3단계 주소를 다시 열어서 **"스터디방 확인 ✅"**이 뜨면 설정 끝!

### 평소 사용법 (봇에게 개인 메시지로)

| 이렇게 보내면 | 이렇게 돼요 |
|---|---|
| `/members` | 관리 중인 멤버를 한눈에 보여줌 (아래 예시) |
| `/kick 12345678` | 그 UID 멤버를 바로 내보냄 |
| `/keep 12345678` | 그 멤버는 자동 정리에서 뺌 (한 번 더 보내면 다시 포함) |
| `/autokick on` | 자동 정리 켜기 |
| `/autokick off` | 자동 정리 끄기 |
| `/help` | 명령어 목록 |

`/members` 예시:
```
👥 스터디방 관리 멤버
자동 정리: 꺼짐 ⏸ — 대상만 표시하고 내보내지는 않아요
🔴 정리 대상 1 · 🟡 주의 1 · 🟢 정상 2 · 🛡 제외 0 · ⏳ 대기 1

🔴 정리 대상
· @alice · UID 123456 · 입장 31일째 · 최근 30일 동안 거래 기록 없음

🟡 주의 (7일 안에 거래 없으면 정리)
· @bob · UID 234567 · 입장 26일째 · 23일 넘게 거래 없음

🟢 정상
· @carol · UID 345678 · 입장 12일째 · 유예 18일 남음
· @dave · UID 456789 · 입장 40일째 · 최근 거래 확인 2일 전

⏳ 승인 대기 (알림의 승인 버튼을 눌러주세요)
· @eve · UID 567890
```

### 추천 순서

1. 처음 1~2주는 **자동 정리를 꺼둔 채로** `/members`의 🔴/🟡 표시가 실제와 맞는지 확인합니다. 처음엔 꺼져 있어서 아무도 내보내지 않습니다.
2. 맞으면 `/autokick on`을 보냅니다. 그때부터 경고 DM과 자동 정리가 진행됩니다.
3. 내보내진 사람도 영구 차단은 아니라서, 거래를 다시 시작하고 사이트에서 재신청하면 다시 들어올 수 있습니다.

### 문제가 생기면

- **승인 버튼을 눌렀는데 "초대 링크 생성 실패"** → 1단계 권한(초대 링크)을 확인하세요.
- **봇에게 `/help`를 보내도 명령어 목록이 안 옴** → 3단계 주소를 다시 열어서 ❌ 항목을 확인하세요.
- 그래도 안 되면 화면을 캡처해서 Claude에게 보내주세요.
