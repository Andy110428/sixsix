Gate.io API 연동 (거래량 확인·랭킹용, 선택)

Read-Only(읽기 전용) 권한의 키만 사용하세요. 출금·거래 권한은 요구하지 않아요.
API 키는 어떻게 발급하나요?
  1. Gate.io 웹사이트에 로그인 → 우측 상단 프로필 아이콘 → "API 관리(API Management)" 이동
  2. "API 키 생성" 버튼 클릭
  3. 권한(Permissions) 목록에 지갑(Wallet)·현물거래(Spot Trade)·마진·선물거래(Futures) 등 여러 항목이 나와요. 이 중 딱 2개만 "읽기 전용(Read Only)"으로 켜주세요: ① 지갑(Wallet) — 계정 소유 확인용, ② 선물거래(Futures Trade) — 아래 "내 거래량 동기화" 버튼이 선물 체결 내역을 읽어서 거래량을 계산하는 데 필요해요
  4. 나머지 현물거래(Spot)/마진/옵션 등은 전부 꺼진 상태(비활성) 그대로 두세요 — 거래량 확인에 필요 없어요
  5. 어떤 항목이든 "읽기+쓰기(Read & Write)"나 "출금(Withdraw)" 권한은 절대 켜지 마세요 — 켜져 있다면 반드시 꺼주세요
  6. IP 화이트리스트는 비워둬도 괜찮아요
  7. 생성 완료 후 나오는 API Key와 Secret Key를 복사해서 아래에 붙여넣으세요 (Secret은 그때 한 번만 보여지니 꼭 복사해두세요)
